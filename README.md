# Leveraging Google Trends for Monitoring Health Events in Digital Surveillance of Influenza-like Illness

This repository contains the code and analysis supporting the manuscript of the same name.

We evaluate whether Google Trends (GT) search volumes for Influenza-like-illness (ILI) related terms reflect the behaviour of ILI-related primary health care (PHC) encounters over time in Brazil, to assess GT as an open, auxiliary ("sidecar") indicator for situational awareness when official PHC data are delayed or unavailable.

## Analyses
- Temporal association between GT and PHC series: rolling Pearson correlation with moving block bootstrap CIs, tested at lags of 0–3 weeks (27 states × 3 term categories)
- Association of correlation stability with state-level digital connectivity (IBC)
- Synchronization of growth signals between GT and PHC series (Bayesian exponential growth model)
